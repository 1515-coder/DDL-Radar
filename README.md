# DDL Radar

> 本地优先的课程与截止日期聚合工具。项目开发使用了 AI 辅助；应用运行时不调用 AI，课程、登录状态和本地数据不会发送给 AI 服务。

DDL Radar 用于汇总本人有权访问的在线课程、作业、测验、考试和问卷，并提供待办、日历、课程筛选及本地多账户管理。目前提供 Windows 桌面版和 Android 版。

## 设计原则

- **本地优先**：课程、任务和账户数据保存在本机，不建立云端账户。
- **用户确认登录**：认证完成后由用户主动确认，不使用无限静默轮询。
- **最小化请求**：只在登录、手动同步或启用启动自动更新时访问所选教学平台。
- **失败可恢复**：单个平台失败不会清空其他平台结果，并尽量保留上一次成功缓存。
- **账户隔离**：不同本地账户的登录状态、缓存和偏好互不共享。

## Windows 版主要功能

- 按平台和学期归类课程，支持单门、多选、整学期及整个平台选择。
- 默认显示当前学期课程，可随时恢复默认选择。
- 按待完成、已逾期、全部和已完成筛选任务，并提供列表与日历视图。
- 默认采集作业、测验/考试和问卷；公告、章节、课堂、讨论、互动、分组学习、笔记和练习本可按需勾选。
- 延河课堂资料先生成文件清单，再由用户勾选下载；完成后自动打开下载目录。
- 支持导出 Excel、CSV 和 JSON。
- 支持多个本地账号，并可分别启用 MOOC、延河课堂或两个平台。
- 提取失败时弹出提示，同时保留上一次成功数据。

## 直接使用 Windows 版

双击 `MOOC-DDL.exe`。程序会在 EXE 所在目录创建本地数据目录，因此建议先将 EXE 放进一个固定文件夹，不要直接在压缩包或临时目录中运行。

首次启动时：

1. 设置软件加密密码。
2. 选择“不记住”“一天”或“一周”。
3. 输入本地账号名称，并勾选需要采集的平台。
4. 点击“登录新账号”。
5. 在打开的 Edge 窗口中完成当前平台的登录或认证。
6. 回到 DDL Radar，点击“我已完成认证”。
7. 如果随后要求认证另一个平台，重复第 5、6 步。

程序不会静默反复探测登录接口。只有点击“我已完成认证”后，Python 才会验证一次登录状态并继续读取课程；如果验证失败，会显示错误提示，重新刷新即可再次认证。

## 日常使用

### 刷新课程与任务

点击右上角“刷新”。作业、测验/考试和问卷始终采集，其他栏目可在弹窗中选择。已有登录状态有效时会直接读取；登录失效时，程序会打开 Edge，并等待用户点击“我已完成认证”。

### 选择课程

左侧课程区支持：

- 勾选任意多门课程；
- 勾选某个平台的全部课程；
- 勾选某一学期的全部课程；
- 点击“恢复默认”，重新选择当前学期课程。

### 下载课程资料

启用了延河课堂的平台账号会显示“课程资料”按钮。点击后程序先扫描资料，再按课程列出文件。勾选需要的文件并开始下载，文件保存在 `downloads/`，完成后资源管理器会自动打开对应目录。

### 导出

点击“导出”，可选择 Excel、CSV 或 JSON。桌面版文件保存在 `exports/`。

## 本地数据与安全

- `.data/accounts.dat`：本地账号注册表，不包含平台明文密码。
- `.data/accounts/<账号ID>/browser-profile`：两个平台的浏览器登录状态。
- `.data/accounts/<账号ID>/artifacts`：课程、任务、公告及栏目提取结果。
- `downloads/`：下载的课程资料。
- `exports/`：导出的表格或 JSON。

账号注册表与浏览器登录状态使用 Windows DPAPI 和软件密码保护。解锁缓存同样受当前 Windows 用户保护，并按用户选择在“不记住”“一天”或“一周”后失效。

请注意：

- 不要把 `.data/` 目录发送给别人。
- 忘记软件加密密码后无法恢复原登录状态，需要重新建立本地账号并登录平台。
- 建议用普通权限运行，不要在普通权限和“以管理员身份运行”之间切换。
- 本工具不能防御已经控制当前 Windows 登录账户的恶意程序。

## 从源码运行

要求 Windows 10/11、Python 3.11 以上及 Microsoft Edge。建议使用 Python 3.12。

在 PyCharm 中打开项目，将项目解释器设置为 `.venv`；或在 PowerShell 中执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe launcher.py desktop
```

无需激活虚拟环境。若 PowerShell 禁止执行 `Activate.ps1`，直接使用上述完整解释器路径即可。

## 测试

```powershell
.\.venv\Scripts\python.exe -m pytest -q

```

## 在 PyCharm 环境中打包

项目使用 PyInstaller 和 `mooc-ddl.spec` 生成单文件 Windows 程序。确认 PyCharm 使用项目 `.venv` 后，在 PyCharm Terminal 中执行：

```powershell
.\.venv\Scripts\pyinstaller.exe --noconfirm --clean mooc-ddl.spec
```

成品位于 `dist/MOOC-DDL.exe`。打包规则只包含程序依赖与 `web/` 前端资源，不会把 `.data/`、Cookie、课程资料、提取结果或导出文件放入 EXE。

## 常见问题

### 点击确认后提示认证未通过

先确认 Edge 中已经进入目标平台的课程页，而不只是停留在统一身份认证页面，然后重新刷新并再次确认。

### 延河课堂能看到课程，但没有作业或测验

延河课程和智园课堂内容使用不同认证。程序可能继续打开智园课堂页面；完成后必须回到主界面再次点击“我已完成认证”。

### 某些课程或栏目为空

空结果不等同于接口不存在。可能是课程本身没有内容、教师尚未发布、课程不属于当前学期，或当前账号没有接口权限。界面会保留成功结果，并在失败时给出提示。

### 课程资料下载失败

重新打开“课程资料”生成最新清单。旧清单中的下载地址可能已经失效；也请确认延河与智园认证仍然有效。

### 杀毒软件提示未知程序

PyInstaller 单文件程序会在启动时解压自身，部分安全软件可能产生误报。请只使用自己构建或可信来源提供的 EXE，并可通过文件哈希核对版本。

## 使用范围

本工具用于整理本人有权访问的课程信息。请遵守学校和课程平台的使用规则，不要高频调用接口、绕过权限或传播受限课程资料。
