# DDL Radar Android 1.0.5

DDL Radar 是一个本地优先的 Android 课程与截止日期整理工具。它可以读取中国大学 MOOC、延河课堂和智园课堂中当前账号有权访问的课程、作业、测验及考试信息，并统一显示在待办、日历和课程页面中。

应用不会建立云端账号，也不会上传本地课程数据。只有用户主动登录、同步或启用启动自动更新时，应用才会访问所选教学平台。

## AI 使用说明

Android 版在开发过程中使用了 **OpenAI Codex** 辅助进行代码草拟、重构、界面迭代、错误排查和文档整理，相关修改由项目维护者审阅并通过本地构建与 Lint 检查。

应用运行时不包含 AI 功能，不调用 OpenAI API，也不会把课程内容、登录状态、账号、任务或诊断数据发送给 OpenAI 或其他生成式 AI 服务。

## 主要功能

- 支持 MOOC、延河课堂和智园课堂应用内登录，由用户点击“我已完成认证”确认。
- 按未完成、已逾期、已完成以及作业、测验与考试多级分类任务。
- 支持按时间、按平台和“全部任务”三种显示方式。
- 点击任务可查看平台详情，并可编辑本地备注、完成状态及紧急程度。
- 支持红、黄、绿、蓝四级优先级和自动重排序。
- 日历支持切换月份、返回今天以及点击日期查看日程。
- 日历日期和日程卡继承任务优先级；同一天优先显示最高等级颜色。
- 课程按 MOOC、延河 / 智园课堂展示，学期和时间收纳在课程详情中。
- 支持课程、学校和学期模糊搜索，并可打开课程详情。
- 支持在课程详情中下载单门课程资料；账户侧栏提供独立批量下载页，可按课程或资料时间分组勾选智园课堂允许下载的课件和附件。下载过程显示实时进度，默认保存到 `Downloads/DDL Radar`，也可另选文件夹。
- 支持多个本地账户，各账户的密码、平台登录状态、缓存和优先级彼此隔离。
- 支持启动自动更新，不会自动切换当前页面。
- 可选启动时弹窗提醒未来 48 小时内截止的未完成任务。
- 登录状态区分“已认证”“待联网验证”和“未认证”；同步失败时保留上一次成功缓存。

## 安装

1. 从 GitHub Releases 下载 `DDL-Radar-Android-1.0.5.apk`。
2. 将 APK 发送到 Android 手机并打开。
3. 如果系统阻止安装，请仅对当前文件管理器临时允许“安装未知应用”。
4. 安装完成后可关闭该授权。

1.0.3 起使用项目独立的长期 Release 证书签名。由于 1.0.2 使用的是 Debug 证书，1.0.2 无法直接覆盖升级到 1.0.3；首次升级需要卸载旧版并重新登录平台。后续正式版本会继续使用同一证书，可正常覆盖升级。

## 1.0.5 更新

- 新增独立的课程资料批量下载页，可按课程或资料时间分组勾选。

## 首次使用

1. 打开左侧账户栏，进入“登录与切换账户”。
2. 输入本地账户名称和密码，点击“创建或切换账户”。
3. 进入“平台登录与同步”，勾选需要的平台。
4. 点击平台右侧“登录”，在应用内网页完成认证。
5. 进入平台课程页面后点击“我已完成认证”。
6. 对其他平台重复以上步骤。
7. 点击“同步已勾选平台”读取课程和任务。

MOOC 使用桌面网页模式，以便正常操作验证码并获取课程接口所需的登录状态。

## 自动更新与提醒

“打开应用时自动更新”默认开启。当前账户存在有效登录状态时，应用启动后会同步已勾选的平台，并刷新当前正在查看的待办、日历或课程页面。同步不会自动跳转页面。

不希望启动时联网时，可关闭自动更新。关闭后应用只读取本地缓存，直到用户手动同步。

开启“打开应用时提醒两天内截止任务”后，应用启动或同步完成时会根据手机系统时间检查本地任务。若存在未来 48 小时内截止的未完成任务，会显示极简提醒窗口。该功能不是后台推送，不申请系统通知权限，也不会为了提醒而后台联网。

## 优先级

- 红色：最高优先级；
- 黄色：较高优先级；
- 绿色：普通优先级；
- 蓝色：低优先级或默认状态。

优先级保存在当前本地账户下，并用于待办排序、日历日期圆点和当日日程色条。

## 多账户

每个本地账户分别保存平台登录状态、课程与任务缓存、昵称、头像、任务备注、状态和优先级。

忘记本地密码时可选择“忘记密码并重建所填账户”。重建会删除该账户原有的平台登录状态、缓存和个人资料，无法恢复。删除账户同样会永久清除该账户数据。

## 本地数据与隐私

- 课程、任务和偏好保存在 Android 应用私有目录。
- 平台 Cookie 和认证快照使用 Android Keystore 中的不可导出密钥进行 AES-GCM 加密。
- 本地账户不保存明文密码，只保存密码校验值。
- Android 系统备份已关闭，明文 HTTP 已禁止。
- 应用没有遥测、广告、统计或云端存储服务。
- WebView 会拦截 Google Analytics、Google Tag Manager 和平台访问统计请求。
- 登录网页发生域名解析错误时会额外验证两次；连续三次失败才清理网页资源缓存，不删除 Cookie、账户、课程和任务数据。
- 请求诊断会移除 Cookie、Token 和查询参数值，但分享前仍建议人工检查。

## 当前限制

- 教学平台接口和网页结构变化可能导致部分详情暂时无法读取。
- 某些延河课程需要额外的智园课堂权限才能读取作业和测验。
- 平台未返回详情时，任务会显示“暂无平台详情”。
- 截止提醒只在打开应用或同步完成后出现，不是系统级后台通知。
- 部分历史课程可能因账号权限限制而被跳过，界面会保留同步告示。

## 从源码构建

要求 Android Studio、Android SDK 35 和 JDK 17。在 `android-app` 目录执行：

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat assembleDebug lintDebug --offline
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

构建 Release：

```powershell
$env:DDL_RADAR_KEYSTORE_FILE = "D:\path\to\ddl-radar-release.jks"
$env:DDL_RADAR_KEYSTORE_PASSWORD = "<store password>"
$env:DDL_RADAR_KEY_PASSWORD = "<key password>"
$env:DDL_RADAR_KEY_ALIAS = "ddl-radar"
.\gradlew.bat assembleRelease lintRelease --offline
```

Release APK 位于 `app/build/outputs/apk/release/app-release.apk`。签名信息只从环境变量读取，不应将密钥、密码或本机签名配置提交到 Git。必须妥善备份 Release 密钥；密钥丢失后将无法为现有安装继续发布可覆盖升级的版本。

## 使用范围

本工具只用于整理用户本人有权访问的课程信息。请遵守学校和课程平台规则，不要高频请求接口、绕过访问权限或传播受限课程资料。
